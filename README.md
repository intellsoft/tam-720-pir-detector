## 📖 دربارهٔ این پروژه

این ریپازیتوری، **یک الگو و نمونهٔ عملی** برای ساخت **شبیه‌سازهای تعاملی** تجهیزات الکترونیکی است. در این نمونه، برد سنسور **TAM 720** به‌صورت یک تصویر SVG برداری شبیه‌سازی شده و کاربر می‌تواند با حرکت موس یا لمس، روی هر بخش کلیک کند و توضیحات کامل، مشخصات فنی و تنظیمات آن بخش را ببیند.

هدف این پروژه، ارائهٔ یک **قالب قابل استفادهٔ مجدد** برای توسعه‌دهندگان، تولیدکنندگان محتوا و شرکت‌های حوزهٔ امنیت و سخت‌افزار است تا بتوانند راهنماهای تعاملی مشابهی برای محصولات خود بسازند.

## ✨ ویژگی‌ها

- **کاملاً برداری (SVG):** کیفیت بالا در هر اندازهٔ صفحه‌نمایش، بدون افت کیفیت.
- **تعاملی:** هاور برای نمایش توضیح کوتاه، کلیک/لمس برای نمایش پنل کامل توضیحات.
- **تنظیمات زنده:** تغییر وضعیت جامپرها (LED و حساسیت) به‌صورت بصری روی برد اعمال می‌شود.
- **دوزبانه‌پذیر:** ساختار متن‌ها به‌گونه‌ای است که به‌راحتی می‌توان زبان دیگری اضافه کرد.
- **بدون وابستگی:** تنها با HTML، CSS و JavaScript خالص — بدون هیچ کتابخانهٔ خارجی.
- **دسترس‌پذیری:** پشتیبانی از صفحه‌خوان، ناوبری با کیبورد (Tab و Enter) و ویژگی‌های ARIA.
- **سئو (SEO):** شامل متاتگ‌های Open Graph، Twitter Card و داده‌های ساختاریافتهٔ JSON-LD.
- **واکنش‌گرا (Responsive):** نمایش مناسب در موبایل، تبلت و دسکتاپ.
- **آمادهٔ انتشار در GitHub Pages:** کافی است فایل را در ریپازیتوری قرار دهید.
